# ☁️ SKPL Cloud Plugin ☁️

A plugin to easily deploy your SKPL project to [SKPL Cloud](https://cloud.strapi.io). Provides a UI to select a deployment method and launch your project in a few clicks.

---

## ✨ Features

- Choose between **SKPL Cloud dashboard** (recommended) and **CLI** deployment methods
- Built-in guidance and quick access to documentation
